# Application evidence

- Trace every metric, date, job title and technology in these files to the master CV or to a line the user confirmed in conversation; an unsourced claim fails the reference check.
- Where no source exists, write `[TK: <what is missing>]` and list it under `## Placeholders to fill` with the question that fills it. Never substitute a rounded, benchmark or adjacent figure.
- Edit the master CV first when the change is reusable, then select from it for the application.
- Before finishing, run `grep -n "\[TK:" <file>` and confirm each hit has its question listed.
