# Pre-submit checklist

Read this before submitting a response. Each line has an owner who ticks it; the response
does not leave until every line is ticked or deliberately waived in writing by the bid
owner.

## Requirements

| Check | Owner |
| --- | --- |
| Every requirement in the compliance matrix has a response | Bid manager |
| Every mandatory requirement is answered, and each "does not comply" is deliberate | Bid manager |
| Clarification answers from the buyer have been applied to the affected responses | Bid manager |
| Narrative claims agree with the matrix, line by line | Bid manager |

## Sign-offs

| Check | Owner |
| --- | --- |
| Terms, exceptions and deviations reviewed and stated in the format the RFP asks for | Legal |
| Every security, privacy and compliance answer reviewed against current evidence | Security |
| Certification scopes stated exactly as the report or certificate states them | Security |
| Every Planned answer has a date range and the non-commitment wording | Product |
| Pricing approved, in the buyer's template, with assumptions and validity period stated | Pricing or finance |
| Reference customers named only with their written permission | Customer marketing |

## Content hygiene

| Check | Owner |
| --- | --- |
| No other customer's name, data, logo or confidential detail anywhere in the response | Bid manager |
| No internal comments, tracked changes or hidden sheets left in the files | Bid manager |
| Product names, plan names and version numbers are current | Product marketing |
| Answers past their library review date were re-verified by their owners | Answer owners |

## Format and submission

| Check | Owner |
| --- | --- |
| File formats, naming, page and word limits as specified | Bid manager |
| Required forms completed and signed by an authorised signatory | Legal |
| Submission portal access tested, and a test upload done, before the deadline day | Bid manager |
| Deadline time and time zone confirmed in writing | Bid manager |
| Submission planned for at least a day before the deadline | Bid manager |
| Confirmation of receipt saved | Bid manager |

## After submission

| Check | Owner |
| --- | --- |
| New answers added to the library with owner and review date | Answer owners |
| Outcome and evaluator feedback recorded when known | Bid manager |
| Bid score and outcome passed to the win-loss review | Bid manager |
