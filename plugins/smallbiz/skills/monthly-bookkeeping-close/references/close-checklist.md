## One-page checklist

Copy it into the month's folder and tick as you go.

```text
Month: ______  Date closed: ______  Time taken: ____ min
[ ] 1  Every account reconciled; closing balance matches statement to the cent
[ ] 2  Receipts attached above threshold; the rest photographed into the folder
[ ] 3  Uncategorised count is 0; new merchants added to rules list
[ ] 4  Ageing receivables reviewed; next ladder step started for each overdue invoice
[ ] 5  Subscriptions reviewed; cancellations noted
[ ] 6  Owner draws booked apart from expenses
[ ] 7  P&L compared with last month; lines over 20% explained
[ ] 8  Rolling turnover updated; threshold percentage and 30-day forward figure recorded
[ ] 9  Period locked; reports exported and filed
[ ] 10 Hand-off paragraph sent
```

## Merchant rules list

One row per recurring merchant. The aim is that most transactions categorise themselves, leaving the month's time for exceptions.

| Merchant text contains | Category | Tax treatment | Notes |
| --- | --- | --- | --- |
| Name as it appears on the statement | Ledger category | Standard, zero-rated, exempt, outside scope, or not claimable | Why, if not obvious (for example, mixed use, split 50/50) |

Review rules each quarter. A rule that matches too broadly (a supermarket that sometimes supplies the business) files private spending as a cost, which is the sort of error an enquiry looks for.

## Common reconciliation differences

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| Books and statement differ by one transaction | A payment booked but not yet cleared, or entered twice | Check the date and the duplicate |
| Books differ by a small, repeated amount | Processor fees netted from payouts | Book gross income and fees separately |
| Difference equals a transfer | Transfer booked on one side only | Book the other side |
| Difference equals a refund | Refund booked as income | Book as a credit note or negative sale |
| Difference constant across months | Opening balance wrong | Correct the opening balance, not each month |
| Foreign currency account off by pennies | Exchange rate differences | Book to an exchange gain or loss line |

## Threshold tracking table

Record the threshold from the authority's page, the date you read it, and the measuring rule it uses.

| Month end | Rolling 12-month taxable turnover | Threshold | Percent | Next 30 days expected | Action |
| --- | --- | --- | --- | --- | --- |
| | | | | | None under 70%; plan at 70%; register or confirm exemption at the point the rule requires |

Notes for the action column:

- At 70%, write down the date at current pace that the threshold would be reached, and what registering would do to your pricing (the tax you would add or absorb).
- The forward test looks at expected turnover over a short window on its own. A single large contract signed this month can trigger it with no history.
- Taxable turnover usually excludes some supplies (exempt or outside scope); use the authority's definition rather than total income.
- Write the registration deadline rule beside the table so nobody has to look it up in a hurry.
