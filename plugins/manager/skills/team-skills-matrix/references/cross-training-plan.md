# Cross-training plan

Read this when pairing: a plan template with staged gates, how to choose the learner and
what to do at the quarterly rescore.

## In this file

- Plan template
- Choosing the learner
- Gates
- Quarterly rescore

## Plan template

| Field | Entry |
| --- | --- |
| Capability | The row text, as written in the matrix |
| Holder | Name |
| Learner | Name |
| Current and target level | For example 0 to 2 |
| Start and target date | Dates, not "next quarter" |
| Time freed | What is removed from each calendar, in hours per week |
| Stage 1, shadow | The learner watches at least two real occurrences or drills, one clean and one with a known snag; gate: explains each step back to the holder (the watch rung of `shadow-reverse-shadow`) |
| Stage 2, reverse | The learner assists, then does it with the holder watching, in a real case (the assist and do-with-watcher rungs) |
| Stage 3, solo | The learner does it alone; the holder is reachable and reviews afterwards (the solo rung) |
| Gate owner | The lead, plus the holder |

## Choosing the learner

Choose someone who wants the capability or whose role will need it, who has the
scheduling slack, and who is not already the learner on another pairing. The most junior
person is not automatically right: a capability at the edge of incident response is a poor
first lesson for a new joiner. Avoid picking the colleague who is already the second
holder of three other capabilities, which would move the single point rather than remove
it.

## Gates

From stage 2 on, a gate is passed when the learner has done the task in a real case, or a faithful drill if
real ones are rare, to the standard the holder would accept, and both the holder and the
lead agree. Write down what the learner did. A gate that is passed by time elapsed alone is
not a gate. For knowledge the holder cannot easily articulate, use
`tacit-knowledge-elicitation` before stage 1.

## Quarterly rescore

At each rescore compare to the last sheet: flags closed, flags new, pairings completed,
pairings stalled. For a stalled pairing ask whether the time was not freed, the learner was
the wrong choice or the capability was harder than planned, and change that one thing.
Retire a row that no longer appears in incidents or roadmap, and add rows from the quarter's
new incidents. Restate the sentence that the matrix is not used in reviews or pay.
