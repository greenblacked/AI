# Writing pillars

## The test

A pillar is a decision, so it must be possible to lose by it. Apply three questions to every candidate:

1. Could a reasonable team choose the opposite and make a good game? If not, it is a value.
2. Can you name a feature it excludes? If not, it decides nothing.
3. Would a new hire reading it alone, without the team, build something different because of it? If not, it is too vague to transmit.

## Forms that work

**X over Y.** Both sides are good; the pillar says which wins when they collide. "Legible over spectacular" means that when a screen full of effects hides an enemy attack, the effects lose.

**A limit stated as a promise.** "Every run fits in twenty minutes" is a pillar a feature can break by a number a stranger can check.

**A verb for the player.** "The player improvises with what they carry" excludes scripted solutions and demands systems that combine. Prefer it to an abstract noun such as "emergence".

## Forms that do not

- A bare adjective or noun: "Immersive", "Depth", "Polish". Everything is for these.
- A genre label: "A tight action platformer" describes the category, not a choice inside it.
- A feature list wearing a pillar's name: "Crafting, base building, co-op". These are contents; the pillar is why they belong.
- A negation of something nobody wants: "No bugs", "Not boring".

## Worked rewrites

| Vague | Rewritten | Excludes |
| --- | --- | --- |
| Meaningful choices | Choices cost something you cannot get back | An undo button, free respec |
| Accessible | Learnable in one session without a tutorial screen | Systems that need a codex to be understood |
| Rich world | The world answers what the player does | Large static set dressing with no reaction |
| Fast-paced | Never more than five seconds from the next decision | Long unskippable travel and loading beats |

## Checking the set

Read the pillars aloud in order. If two could be swapped without anyone noticing, merge them. If one sounds like a pitch line, ask what it excludes. If the team cannot recite them from memory a week later, the set is too long or too abstract.
