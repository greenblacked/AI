# Page shapes

A shape is how a whole page is arranged: what leads, how the parts relate, what the eye
does between them. It is separate from the material (colour, type, texture), which
`references/materials.md` covers. Choose the shape first and the material second, because a
material cannot rescue a shape that does not fit the content.

Shapes are compared by fingerprint, not by name. Two pages with different names for their
layouts can still be the same page. Compare on six axes.

## The six axes

| Axis | Values to choose from |
| --- | --- |
| Heading placement | above the block; hanging in the margin; laid over an image; running head; inline with the body; one statement with no section headings |
| Body composition | one column; two-column split; tiles; index list; full-bleed stack; captioned figures |
| Divider style | whitespace only; hairline rule; change of background band; running numbers; none, the image edge does it |
| Button voice | text link with an arrow; solid block; outlined; a link inside a sentence; a command to copy |
| Image treatment | full-bleed; cropped tiles; framed with a caption; cut-out on a band; no images, type or a diagram instead |
| Reveal pattern | none; on load only; sequential on scroll; a pinned visual that changes state; on interaction |

**The neighbour test.** Write down the fingerprint of the shape you are leaning towards.
Then ask what a different request in the same category would be given. If it would land on
the same fingerprint, change at least two axes. Changing one axis tends to produce the
same page in a different coat.

## The shapes

Each entry gives the label, how it is arranged, what content suits it, and the fingerprint
in axis order: heading, body, divider, button, image, reveal.

### Tile mosaic with a lead tile

A grid of tiles in mixed sizes, one clearly largest. The lead tile holds the strongest real
thing; the others are the supporting items at their natural weight. Suits a body of
varied, showable work: a portfolio, a menu with a signature dish, an event with several
strands. Fingerprint: laid over the tile; tiles; background band per tile; text link with
an arrow; cropped tiles; on load only.

### Long column with marginal notes

One narrow readable column, with asides, sources and definitions set in the margin beside
the line they belong to. Suits an argument, a case study or a report where the reader will
read straight through and the asides are earned. Fingerprint: hanging in the margin; one
column; whitespace only; a link inside a sentence; framed with a caption; none.

### One statement that owns the first screen

A single large sentence fills the first screen with almost nothing else; the rest of the
page is short and follows from it. Suits a position, a manifesto or a product with one
claim that is true and strong. It fails when the sentence is vague, so the claim has to be
specific. Fingerprint: one statement with no section headings; full-bleed stack; change of
background band; solid block; no images; on load only.

### Page opened by one real number

The first screen is one figure the organisation can stand behind, with its source beneath
it. Everything after explains how the number came about. Suits anything with a measured
result. It is unusable without a real number, and a rounded or invented one is worse than
none. Fingerprint: above the block; one column; hairline rule; text link with an arrow; no
images, type instead; sequential on scroll.

### Sequence of real captures

Screenshots or photographs of the real product or place, in the order a visitor would meet
it, each with a short caption saying what to notice. Suits software and physical places
where seeing it is the argument. Captures are checked for personal data first. Fingerprint:
running head; captioned figures; whitespace only; outlined; framed with a caption;
sequential on scroll.

### One held visual that changes state

A single visual stays in view while text panels scroll past it, and the visual changes with
each panel: a diagram that fills in, a product that rotates through states. Suits an
explanation with stages that belong to one object. The scroll behaviour needs the reduced
motion version to show the final state with the panels as plain text. Fingerprint: inline
with the body; two-column split; none; a link inside a sentence; cut-out on a band; a
pinned visual that changes state.

### One large photograph per screen

Each screen is a single photograph at full size with a line or two of text over or beside
it. Suits places, food, crafts and travel, where the photographs are good and there are
few of them. Fingerprint: laid over an image; full-bleed stack; none, the image edge does
it; text link with an arrow; full-bleed; sequential on scroll.

### Dense index of the category's own items

A close, scannable list of the things the category is made of: every dish, every route,
every model, in a table-like list with the facts a visitor compares on. Suits catalogues,
timetables and directories where the visitor arrives knowing what they want. Fingerprint:
above the block; index list; hairline rule; text link with an arrow; no images; none.

### Page whose subject is type

Letterforms are the content: very large specimens, set at different sizes and weights,
with the text describing them. Suits a typeface, a print studio, a signwriter. The type
must be real and licensed for the page. Fingerprint: running head; tiles; background band
change; outlined; no images, type instead; on interaction.

### Numbered process

Steps that really happen in order, numbered, each with what the visitor does and what they
get. Suits an order flow, a programme, an application. It fails when the steps could be
reshuffled, which means they are not a sequence. Fingerprint: hanging in the margin; one
column; running numbers; solid block; cut-out on a band; sequential on scroll.

### Uniform grid of variants

Many instances of one thing, shown the same way so the differences stand out: colours of a
product, sizes of a part, plans of a trip. Equal weight is correct here because the items
are equal. Fingerprint: above the block; tiles; whitespace only; solid block; cropped
tiles; on interaction.

### Page organised around one diagram or map

A diagram, map or plan is the spine, with the text attached to places on it. Suits
anything spatial or structural: a venue, a route, a system. It needs a text alternative
that carries the same information. Fingerprint: laid over an image; captioned figures;
none, the figure edge does it; text link with an arrow; framed with a caption; on
interaction.

### Two-column split of claim and proof

Each block pairs a claim on one side with the evidence for it on the other: a quote, a
figure, a capture, a document. Suits a page that has real proof for several distinct
claims. Where a claim has no proof the block is left out rather than filled. Fingerprint:
above the block; two-column split; hairline rule; a link inside a sentence; framed with a
caption; sequential on scroll.

### Question-led page

The sections are the questions a visitor actually asks, in the order they ask them, each
answered plainly under the question. Suits an unfamiliar service, a decision with risk, a
page that serves people who are unsure. Fingerprint: inline with the body; one column;
whitespace only; a link inside a sentence; no images; none.

### Live demo for a developer tool

The page contains the tool at work: a runnable snippet, a command to copy, a result that
updates as the visitor edits. Suits developer tools where trying it beats describing it.
The demo has to work offline in the page or say plainly that it is a recording.
Fingerprint: running head; two-column split; whitespace only; a command to copy; no images,
a live demo instead; on interaction.

## No shape fits

Some content fits none of these, and forcing it into one is worse than going without.
Use this checklist instead, and record that no shape was chosen and why.

1. Name the visitor's job in one line.
2. Name the one signature element, the strongest real thing the content has.
3. Give each section one composition from the list below, and avoid giving two neighbours
   the same one.
4. Write the fingerprint of the result and run the neighbour test on it.
5. Hold to every floor rule in `references/rules.md`.

## Section compositions

The pieces shapes are built from. Pick one per section.

- A heading over a single column of text.
- A heading hanging in the margin beside the text.
- A full-bleed image with text laid over a quiet part of it.
- A large figure with its source beneath.
- Two columns, claim beside proof.
- A table-like index with facts in columns.
- A framed capture with a caption.
- A pull quote that is a real quote, with attribution and permission.
- A numbered list of steps.
- A tile group with one lead tile.
- A diagram with labels attached to its parts.
- A single line of text and a single action, with room around them.
- A runnable demo.
